# ProfileRender

бла бла бла, бле бле бле, блу блу блу

| Параметр | Информация                              | Пример |
|:--------:|:----------------------------------------|:------:|
|    bg    | Цвет заднего фона                       | 555555 |
|  color   | Цвет текста                             | FFFFFF |
|    w     | Ширина (в пикселях)                     |  650   |
|    h     | Высота (в пикселях)                     |  400   |
|    lh    | Растояние между строками (в пикселях)   |   20   |
|   pad    | Растояние между содержимым (в пикселях) |   30   |
|    ml    | Сколько максимум отображать линий?      |  100   |
|    fs    | Размер шрифта (в пикселях)              |   12   |
